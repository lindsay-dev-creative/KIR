# lyn-norton

Brand name availability research.

`brand-name-availability.html` is a sortable table of 42 candidate names showing
Namecheap registration pricing and Instagram handle status, checked 18 August 2026.

- Domain pricing scraped from Namecheap live search results
- Every domain status cross-verified against registry records (Verisign / Identity Digital RDAP, .co registry whois)
- Instagram handles checked against the public profile endpoint

`email-signature/` holds Lyn Norton's HTML email signature (`kirby-lane-signature.html`)
and its 2x PNG images. The images are served from https://kir.lindsaydev.com/email-signature/img/
for use in Apple Mail and other clients.

Prices and availability move daily. Re-verify before purchasing.
